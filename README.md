**思考题：**

如果在主循环、中断等处使用了HAL_Delay()函数就会导致按钮的检测失效或者执行效果会产生延迟，如果是单纯的延后执行一两秒有大概率是在主循环使用了HAL_Delay()。

我们可以使用HAL_GetTick()函数来获取时间，用相对时间来判断是否执行语句，中断中也可以使用，但要调整HAL_GetTick()中断的优先级高于按钮中断。
